# Eagle Eye Eyewear website

深圳市鹰之眸眼镜有限公司（Eagle Eye Eyewear）官网源码与产品资料库。

Live site: https://eagle-eye-eyewear.com
Hosting: Cloudflare Pages

## Repository layout

- `docs/` — B2B documentation, company profile, catalog text
- `products/` — product images, catalog pages, product descriptions
- `README.md` — this file

## How to update the website

Tell the assistant what you want to change in plain Chinese, for example:

- "在官网首页加一个 CLARIO 老花镜系列入口"
- "把画册目录里太阳镜那段改成……"

The assistant edits files here, commits to `main`, and Cloudflare Pages redeploys automatically.

## Content rules

- Do not invent product specifications, prices, or certifications.
- Keep English copy aligned with the printed catalog.
- Confirm before any external publish or file deletion.
